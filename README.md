Cargo Manifest Validator

A cutting-edge, cyberpunk-themed cargo manifest validation system built with vanilla JavaScript,
HTML5, and CSS3. This application provides real-time validation of cargo manifests with an immersive
terminal-style interface.

Features

Core Functionality

• normalizeUnits() - Converts weight measurements to kilograms without mutating source data
• validateManifest() - Comprehensive validation checking all required fields
• processManifest() - Main processing function with console logging

Validation Rules

Field Requirement

containerId Positive integer
destination Non-empty string (trimmed)
weight Positive number (not NaN)
unit Must be “kg” or “lb”
hazmat Boolean value

UI Features
• Real-time visual validation feedback
• Three output modes: Terminal, JSON, and Visual
• Processing history with quick reload
• Animated cyberpunk interface
• Responsive design for all screen sizes

Usage
1. Open index.html in any modern web browser
2. Fill in the manifest form fields
3. Click “Process Manifest” to validate
4. View results in Terminal, JSON, or Visual tabs
5. Check console output for detailed logs

Technical Details

Weight Conversion
• 1 lb = 0.45 kg (approximate)
• Conversion happens in normalizeUnits()
• Original object remains unmutated

Error Handling
• Missing fields marked as “Missing”
• Invalid fields marked as “Invalid”
• Empty object returned for valid manifests
